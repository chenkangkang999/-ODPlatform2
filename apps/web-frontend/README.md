# 渔见 FishScope 前端

Vue 3 + Vite 单页应用，包含项目介绍、数据理解、模型训练、模型推理、仪表盘、智能助手六个页面。由 Django 后端统一服务构建后的静态文件。

界面采用顶部横向导航，桌面与手机均不使用侧边栏。`src/aquatic.css` 提供水蓝背景、浅蓝边框和主题样式；水纹与鱼群 SVG 为原创静态装饰素材，不表示模型识别结果。

`src/readability.css` 提供放大字号、较高文字对比度和鱼形置信度滑块。类别图标使用 `FishGlyph.vue` 的十种装饰鱼形，保留原有类别名和 class_id 数据顺序，界面不再显示角落序号。主图及全页蓝色水下背景为 AI 生成装饰画，来源记录在 `public/images/SOURCES.md`。

## 开发与构建

需要 Node.js 20.19+ 或 22.12+。

```powershell
cd apps/web-frontend
npm ci
npm run build
```

开发期间运行 `npm run dev`，Vite 将 `/api` 请求代理至 `http://127.0.0.1:8510`。交付预览使用 Django 的同源地址 `http://127.0.0.1:8510/`。

## 数据口径

- 首页 33 类、4,560 张图像、6,034 个实例、15/15 质检为仓库 README 记录。
- mAP50=90.73%、mAP50–95=74.42%、Precision=82.68%、Recall=88.74% 是仓库独立验证集评估记录，不是本机实时指标，也不是测试集结果。
- 实时数据集接入状态、候选权重、实验记录、任务列表通过后端 API 读取。
- 前端列出本地候选权重；推理前由后端加载模型并核验其 33 类标签与 fish 配置完全一致。
- 图片和视频的检测结果不使用模拟数据。视频统计为多帧检测框次，不代表独立鱼的个体数。
- 智能助手未配置大模型时明确显示“本地规则解释”。原始视频不传给大模型；只提交文本与结构化证据。
- 场景照片仅用于装饰，来源见 `public/images/SOURCES.md`。

页面路由使用 URL hash，因此刷新、直接打开任一页面均由 Django 返回同一个入口。
